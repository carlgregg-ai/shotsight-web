## Evidence QA

The Stage 2 claim matrix was treated as the hard constraint. In particular:

- three CPSA shooting methods are presented as recognised options, not universal prescriptions;
- Don Currie/NSCA long-crosser, quartering, cutoff, chandelle, teal, rabbit, driven and true-pair protocols retain attribution;
- OSP quartering remains lineage/method-specific;
- teal disagreement is preserved rather than flattened;
- rabbit `ignore every bounce / average line` wording is removed from accepted guidance;
- driven and passing-overhead geometry remain separated;
- no wall-projection visual claims to reproduce true depth or exact ballistic lead;
- all Sense/Project thresholds, diagnostic scores and novel drill metrics remain `SHOTSIGHT_HYPOTHESIS` unless previously validated.

## Content QA decisions

- Every lesson starts with target classification before technique.
- Ambiguous terms (`teal`, `rabbit`, `overhead`, `pair`, `incomer`) ask/require the discriminating geometry or sequence context.
- A shooter symptom is never treated as the diagnosis itself.
- Corrective actions include a retest so the loop is Learn → Diagnose → Correct → Practice → Verify.
- Visual specs separate target path from gun/method path and require warnings wherever 2D projection or conceptual lead could be misunderstood.
