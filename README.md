# ShotSight Web

Touch-first browser prototype for ShotSight visual training.

## Prototype v2

- Mobile-first Today / Train / Progress navigation
- Drills: Three Bullet, Saccade Ladder, Smooth Pursuit, Quiet Eye
- Games: Whack a Clay, Clay Invaders, Stay on Your Bird, Flash Point
- Full-screen training player designed for touch
- Local progress/history storage
- Installable web-app metadata for iPhone home-screen use

Designed to run as a static site on GitHub Pages with no build step.
